# Background music

Drop one or more **royalty-free / no-copyright** music tracks here
(`.mp3`, `.wav`, `.m4a`, `.ogg`). The pipeline picks a **random** track for each
video and automatically **ducks** it under the narration (sidechain), so the
voice always stays clear.

- More than one track = variety across your daily videos.
- Turn music off anytime in `config.yaml` → `music: enabled: false`.
- Set `music: file:` to a specific filename to always use that one.

## Where to get free music (safe for YouTube, no strikes)
Use only tracks licensed for reuse. Good sources:

- **YouTube Studio → Audio Library** (studio.youtube.com → Audio Library) —
  free, cleared for YouTube, filter by "No attribution required". Best option.
- **Pixabay Music** — https://pixabay.com/music/ (free, no attribution)
- **Incompetech** — https://incompetech.com (CC-BY; credit the composer in the
  description)
- **Chosic** — https://www.chosic.com/free-music/all/

Pick calm, emotional, instrumental tracks (no lyrics) so they don't fight the
Gujarati narration. For moral stories, search moods like *calm, emotional,
inspirational, cinematic, sad piano, meditation*.

> Tip: download 5-10 tracks once and drop them all here — then every video gets
> varied background music automatically, forever.
