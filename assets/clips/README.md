# Clips (your own video)

Drop your own **AI-generated video** or **motion-graphic** clips here
(`.mp4`, `.mov`, `.webm`). The pipeline uses them as scene visuals when
`visuals.provider: local`, mixed with photos from `assets/images/`.

These are for content **you created or have the right to use** — do not put
copyrighted clips from other creators here (see README "Responsible use").
